## ACDEK Enterprise Web Interface
This folder contains the frontend web applications for ACDEK's administrative dashboard, developer portal, and monitoring interfaces.

### Core Frontend Architecture
- **core/**: Frontend foundation components
  - **app.tsx**: Application entry point
  - **router.tsx**: Application routing
  - **store/**: State management
  - **hooks/**: Custom React hooks
  - **themes/**: UI theming system
  - **providers/**: Context providers
  - **layouts/**: Page layout components

- **api/**: API client integration
  - **client.ts**: API client configuration
  - **auth.ts**: Authentication utilities
  - **endpoints.ts**: API endpoint definitions
  - **types.ts**: API data type definitions
  - **interceptors/**: Request/response interceptors
  - **caching/**: API response caching
  - **error-handling/**: API error handling

- **components/**: Reusable UI components
  - **ui/**: Generic UI components
  - **data-display/**: Data visualization components
  - **forms/**: Form elements and validation
  - **layout/**: Layout components
  - **navigation/**: Navigation components
  - **feedback/**: User feedback components
  - **security/**: Authentication UI components
