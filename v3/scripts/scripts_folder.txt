## ACDEK Enterprise Utility Scripts
This folder contains comprehensive developer utilities, data processing scripts, and DevOps automation for the ACDEK platform.

### Development Utilities
- **setup/**: Development environment setup
  - **setup_dev_environment.py**: Complete development environment setup
  - **install_dependencies.py**: Project dependency installation
  - **configure_git_hooks.py**: Git hooks installation for CI checks
  - **create_virtual_env.py**: Virtual environment creation
  - **install_test_tools.py**: Testing tool installation
  - **setup_docker_dev.py**: Docker development environment
  - **configure_ide.py**: IDE configuration generator

- **code_generation/**: Scaffolding and boilerplate
  - **create_plugin.py**: Plugin template generator
  - **create_interface.py**: Interface definition generator
  - **create_component.py**: Component template generator
  - **generate_test.py**: Test file generator
  - **create_docs.py**: Documentation template generator
  - **generate_client.py**: Client library generator
  - **create_benchmark.py**: Benchmark template generator

- **data_generation/**: Test and sample data
  - **generate_traits.py**: Trait data generation utilities
  - **create_semantic_classes.py**: Semantic class generator
  - **generate_test_requests.py**: Test request generator
  - **create_mock_responses.py**: Mock response creation
  - **generate_embeddings.py**: Test embedding generator
  - **create_synthetic_logs.py**: Log entry generation
  - **generate_performance_data.py**: Performance test data
